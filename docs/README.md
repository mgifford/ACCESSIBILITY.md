# Project Documentation

This directory contains repository-specific documentation: how the project is
maintained, how to write for it, and historical records that are useful to
contributors but not to people adopting the accessibility guidance.

For guidance you can use in your own project, start with
[`examples/`](../examples/README.md). For the project's own accessibility
commitment, see [ACCESSIBILITY.md](../ACCESSIBILITY.md).
